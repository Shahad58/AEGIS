## ⚡ 𝑷𝒓𝒐𝒋𝒆𝒄𝒕 𝑶𝒗𝒆𝒓𝒗𝒊𝒆𝒘 | نظرة عامة

**AEGIS** is a premium, interactive industrial dashboard designed to transform raw sensor data into actionable predictive maintenance decisions. It features dynamic data visualization, bilingual support (English/Arabic RTL), and a sleek deep-space glassmorphism design.

The core of the project is a **Full Python Application** powered by **Flask**, **XGBoost**, and **SHAP** for advanced Remaining Useful Life (RUL) estimation and explainable AI diagnostics.

---

## 🚀 3 Steps to Run the Full Experience | خطوات تشغيل التجربة الكاملة

To run the complete interactive project on your machine, follow these three simple steps:

**Step 1 — Clone the repository:**

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
cd YOUR_REPO_NAME
```

**Step 2 — Install dependencies:**

Make sure you have Python installed, then run:

```bash
pip install -r requirements.txt
```

**Step 3 — Run the application:**

```bash
python app.py
```

> 🎉 **Success!** The full interactive app will now be live at `http://localhost:5000` in your browser.
